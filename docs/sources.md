# Where every figure and claim on the site comes from

The rule: a number or a claim of fact appears on the site only if it traces to one of the sources below. If it cannot, it comes off. Reduction percentages are never quoted (the datasheet's "3+3 Stage System Performance" list covers the optional reverse-osmosis stages, is marked for reference only, and is not this product).
